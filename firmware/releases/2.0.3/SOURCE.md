# Corresponding source

CLMD firmware 2.0.3 is GPL-3.0-or-later; linked third-party components retain their notices in notices/.

The source/configuration is in the firmware/ directory of the CLMD GitHub repository, at the matching firmware-v2.0.3 tag. The publisher must create this source tag and keep its source archive available alongside this binary download. Build instructions and the required ESP-IDF 5.5.1 patch are in that repository. No proprietary installation key or separate programmer is required; the board accepts firmware over native USB.

Until the initial GitHub upload, this bundle is staged locally with the corresponding full repository archive. It does not assert that a live release URL already exists.

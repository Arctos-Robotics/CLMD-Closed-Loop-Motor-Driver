# CLMD PCB v3

This is the October 23, 2026 export from the maintainer's `PCB v3` folder. Use the design and manufacturing files from this folder as a set. The September export remains in [pcb-v2](../pcb-v2/) for reference.

| File | Use |
| --- | --- |
| [EasyEDA project](Design%20Files/ProPrj_Arctos1_2026-10-23.epro2) | Editable schematic and PCB layout |
| [STEP model](Design%20Files/3D_PCB.step.zip) | Mechanical fit and integration |
| [Gerber ZIP](Fab%20Files/Gerber_PCB1_2026-10-23.zip) | Four copper layers, outline, drills and other fabrication outputs |
| [BOM](Fab%20Files/BOM_Board1_PCB1_2026-10-23.xlsx) | Parts list for assembly |
| [Pick-and-place](Fab%20Files/PickAndPlace_PCB1_2026_10_23.xlsx) | Placement data for assembly |

The EasyEDA archive includes the schematic. Its schematic page records match the September project aside from the editor metadata, so the [September schematic PDF](../pcb-v2/Design%20Files/SCH_Schematic1_2026-09-22.pdf) is also useful for circuit reference. For assembly, use the October layout and files above. Review stackup and placement in the manufacturer's viewer before ordering.

Current CAD renders: [front](../../assets/board-front.png) · [rear](../../assets/board-back.png). [Rendering provenance](../../assets/README.md).

See [versions and compatibility](../../docs/VERSIONS.md), [wiring](../../docs/WIRING.md) and [ordering](../../docs/ORDERING.md).

The STEP model is supplied as a lossless `.step.zip` download for browser-upload compatibility. Extract the ZIP before opening the STEP file in CAD.
